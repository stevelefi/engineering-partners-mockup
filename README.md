# Engineering Partners — Mockup Website

A static HTML/CSS mockup of a fictional engineering-services company site, built as a design exercise. No build step, no dependencies — just plain HTML, CSS, and a sprinkle of vanilla JS for the mobile nav.

## Pages

- [`index.html`](index.html) — Home
- [`capabilities.html`](capabilities.html) — Capabilities
- [`government.html`](government.html) — Government & Prime Contractor Opportunities
- [`about.html`](about.html) — About Us / Contact

## Running locally

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Stack

Plain HTML, CSS (`styles.css`), and vanilla JS (`script.js`, `footer.js`). No framework, no build tools.
